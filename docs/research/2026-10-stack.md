# Research: stack and tooling (2026-10-08)

**Status:** history. Fed ADR-0001; its notes on a three.js island matter again if real-time 3D
returns.

Versions from the npm registry on 2026-10-07/08. Some vendor docs were unreachable from the
research sandbox; those claims rest on raw GitHub docs or secondary sources.

## Recommendation

**Astro 7.3** static output on GitHub Pages via `withastro/action@v6`; Markdown/MDX content
collections with Zod schemas; **vanilla Three.js r186** (`WebGPURenderer` + TSL, automatic
WebGL 2 fallback) as one capability-gated, lazily imported island; CSS and native View
Transitions by default, **GSAP 3.15** (free incl. former Club plugins) only for real
timelines; assets made in code (TSL/GLSL, procedural geometry, headless Blender `bpy`,
`gltf-transform` 4.5). Guardrails: Playwright screenshot/visual diff, axe, Lighthouse CI, size
budget, link check — all in CI.

## 1. Framework

| | Astro 7.3 | Next 16 static export | SvelteKit 3 static | Vite + React |
|---|---|---|---|---|
| Dated log | Content collections, typed | Own wiring | mdsvex | All by hand |
| Default JS on content pages | Zero (islands) | React runtime | Small runtime | Whole SPA |
| i18n `/` + `/tr/` | Built in | Not with static export | By hand | By hand |
| RSS, sitemap | First-party | By hand | By hand | By hand |

Astro: content-first, Lighthouse 100 by default, islands keep 3D off the content path, runs
on Vite 8 like Recto. Majors every ~6–9 months; small upgrades for static sites; pin and let
Renovate open PRs.

## 2. 3D layer

- **Three.js vanilla** — most docs and training data, no framework lock-in. Chosen.
- R3F 9 / drei 10 — adds React to the 3D chunk; v10 (first-class WebGPU) still alpha.
- Threlte / TresJS — only with Svelte / Vue. Spline — GUI-authored, heavy, opaque: no.

WebGPU: Chrome/Edge 113+ desktop, Chrome 121+ Android 12+, Safari 26 (macOS/iOS 26),
Firefox 141 Windows / 145 Apple Silicon. Not Firefox Android or older iOS. Write TSL so one
code path covers both backends; keep a static poster for no-WebGL.

Loading: HTML/CSS first with a pre-rendered poster → tiny inline gate (reduced motion,
Save-Data, cores/memory, coarse pointer, context creation) → idle/visible/gesture →
`import('./scene/desktop')` or `./scene/mobile`. Fade in after first frame; pause when hidden;
cap DPR on mobile; the canvas is never the LCP element; fixed size so CLS = 0.

Cheap looks on mobile: fake refraction (normal-offset sample of a pre-blurred static
texture + Fresnel rim + 3-tap chromatic offset) instead of `transmission`; caustics as
animated tiling/procedural noise; aura as additive SDF billboards; bloom only on desktop at
half resolution; baked lighting; no real-time shadows on mobile; raymarching desktop-only at
0.5× resolution.

## 3. Animation

CSS, scroll-driven animations and View Transitions by default. GSAP 3.15 for timelines,
ScrollTrigger and SVG morphs. Motion 14 is a fine alternative but pick one. Lenis optional,
desktop only. Theatre.js stalled. Rive/Lottie need GUI editors — only with commissioned files.

## 4. Asset pipeline without a GUI

Procedural geometry and SDF shaders in code; headless Blender (`bpy` 5.2, Python 3.13) with
scripts committed, never `.blend`; `gltf-transform` with meshopt (preferred over Draco) and
KTX2 textures; hand-written SVG components for log illustrations, D3/Plot/Mermaid rendered
to SVG at build time; posters and OG images from Playwright screenshots or `satori`.

| Tool | Verdict |
|---|---|
| Anthropic `frontend-design` skill (official plugin) | Yes — cheap; overridden by our own brand doc |
| Playwright (scripted tests; MCP/CLI for looking) | Yes |
| Chrome DevTools MCP | Yes, for profiling the 3D scene and LCP |
| Blender MCP | Marginal — needs a GUI Blender; headless scripts are reproducible |
| Figma MCP | Only if someone works in Figma |
| Community TSL skills | Optional; read before adopting |

## 5. GitHub Pages

- Root URL requires the repo be named `erendenizk.github.io`; set `site`, omit `base`.
- `actions/checkout` → `withastro/action@v6` → `actions/deploy-pages@v5`; Source = Actions.
- Limits: 1 GB site, ~100 GB/month soft bandwidth, 10-minute deploy timeout.
- No custom headers (no COOP/COEP, no cache tuning); CSP via `<meta>`; no server redirects;
  custom `404`; no Git LFS for assets.
- Private repos publish only on a paid plan.

## 6. Quality gates

1. `astro check` + build; schemas fail on bad frontmatter.
2. Playwright matrix: 1440×900, 1180×820 touch, 390×844 phone; reduced motion; WebGL off
   (poster fallback); `toHaveScreenshot()` with a frozen scene (`?still=1`, seeded RNG).
3. axe on every route template, both locales; keyboard-only test.
4. Lighthouse CI: perf ≥ 0.95 content / ≥ 0.85 3D home (mobile), a11y/BP/SEO = 1, CLS < 0.02.
5. `size-limit`: content JS ≤ 15 KB gz, desktop 3D ≤ 250 KB, mobile ≤ 150 KB, GLB ≤ 1 MB.
6. Link check over `dist/` incl. RSS and hreflang.
