# Research

Dated research, one file per question. Every file opens with a status line, and that line is the
truth when this index and the file disagree. **current**: still describes the site or still guides
work. **closed**: the question was answered; kept as the record. **history** / **superseded**: input
to an older round. Research is evidence, never a decision: decisions are in `docs/adr/` and the owner's
intent in `docs/brief.md`. Figures live in `assets/`.
