# ADR-0003: Direction D, quiet type and one living object

**Status:** accepted 2026-10-08 by the owner · **Rests on:** brief §2.1, §5; ADR-0002;
`prototypes/` A–D

## Context

Four prototypes were built on identical content and tried by the owner: A (the die),
B (a 3D glass bench), C (a pannable 2D workbench) and D (editorial type with one glass object
lit by each project's colour).

## Decision

1. The site follows direction D: an editorial, employer-first site with one signature object.
2. The site is rebuilt from scratch on the stack of ADR-0001; the D prototype is a reference
   for feeling, not code to keep.
3. Before any UI work, a requirements pass answers what the site must contain and how, from
   the view of hiring managers, engineers and friends (`research/2026-10-requirements.md`).
4. Ideas from A, B and C may return later as details (the die drawing, a world layer), only
   through their own ADR.

## Consequences

Content and clarity come first; the "world" ambition of brief §5 is deferred, not dropped.
*Note 2026-10-10:* radical per-page worlds were shown and shelved by the owner (they broke the
site's unity); per-page light stays.
