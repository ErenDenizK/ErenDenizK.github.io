# Journal

One file per working day (`YYYY-MM-DD.md`, under 60 lines): what the owner asked, what was done, what
was decided and why, what is open. It is the bridge between sessions so a fresh context starts from
the record, not from memory (`docs/WORKFLOW.md` §4). Facts and decisions still go to their real home
(brief log, ADRs, PLAN); the journal points at them.
