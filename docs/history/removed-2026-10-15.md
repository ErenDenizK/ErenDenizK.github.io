# Code removed on 2026-10-15

Archived 2026-10-15: superseded by the two-page direction (brief log, 2026-10-15, late night).

The clean-up for the new line removed code that no live page uses. This file is the record: what
each piece was, why it went, and how to get it back. Every file is still in git. The last commit
that holds all of them is `52f9a87` (on `dev`). To restore one file:

```sh
git show 52f9a87:<path> > <path>
```

**Why delete and not move.** `tsconfig.json` type-checks every file in the repo, so `.astro` and
`.ts` files moved under `docs/` would fail `npm run check` (their relative imports break) unless
the folder is excluded. Dead code in the tree also shows up in every search an agent runs, and
that steers new work back to the old design, which is what this clean-up exists to stop. The one
exception, Darkroom's burn-in, is kept as readable files in [`code/`](code/README.md), because the
owner said it may return.
