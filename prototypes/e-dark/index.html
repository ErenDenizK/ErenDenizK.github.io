02A two-track education

School and courses, where I write the code myself. This is the engineering underneath everything else.

  • Computer Engineering at YTU
  • CS50 and similar courses, camps
  • Towards the low level: processors, embedded systems

The products

Projects built by directing AI agents. They teach me project discipline and product sense: specs, decisions, review.

  • Recto, a browser-only PDF editor
  • English Prep, a study app for proficiency exams
  • Eat Map, an iOS app

Both matter. I don't stay away from AI, and I don't let it stand in for the first track.

03How this site is made

The log starts as notes I dictate, often in Turkish. An AI agent edits them into English in my voice, keeps my facts as they are, and I read every draft before it goes up.

The site is built the same way as my projects: I decide and review, agents write most of the code. The glass objects in this prototype are drawn in code as placeholders; the finished ones are modelled in Blender.

01What it is

Open many PDFs, arrange their pages on one light table, annotate, fill, redact, edit text, recognise scans, compare, sign.

02Why

owner to write

03How

  1. PDFium, compiled to WebAssembly, runs in a Web Worker.
  2. Vite, React 19 and TypeScript.
  3. A Content Security Policy limits connections to its own origin.
  4. Every export is re-opened and checked before download.
  5. Redaction removes the content under each mark, then re-reads the output.
  6. End-to-end tests run in Chromium, Firefox and WebKit.

01What it is

Article-led lessons, each a contrast (“Present Perfect vs Past Simple”), then paragraph-cloze tests with explained feedback. Built for learners who already speak English and lack the labels.

10topics
60lessons
241questions

02Why

“I built it for myself and friends sitting the exam.”

03How

  1. No build step: plain HTML, CSS and ES modules.
  2. Zero runtime dependencies, and no innerHTML.
  3. Everything is stored in the learner's own browser.
  4. Content is validated in CI; questions are reviewed blind.
